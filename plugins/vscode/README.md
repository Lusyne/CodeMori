# CodeMori

**代码在哪，文档就在哪。**

在 VS Code 中保存代码快照、检索个人片段与文档摘要，并给源码文件关联飞书、Notion、Obsidian 或本地文档。资料保存在 `~/.codemori/`，与 JetBrains 版本共用，无需额外桌面客户端。

## 使用

- 命令面板运行 `CodeMori: 搜索资料`，在编辑器右侧打开专属面板。
- 选中代码，右键 `CodeMori: 保存选中代码`。标题、场景描述和标签可以编辑；片段不会自动跟随源码变化。
- 当前文件可关联外部文档。面板显示关联摘要；打开原文时可能切换应用。
- 支持来源、标签、项目、收藏筛选，以及编辑、复制、删除和关联修复。
- “更多”提供完整备份导出、预览后导入和工作区重新定位。
- 支持手动／增量索引已保存的 Java、JS/TS、Python 注释，遵守忽略规则，不存储源码正文；点击注释结果跳转。
- 本地 Markdown 支持只读预览；不执行 HTML，不加载图片，正文不进入搜索。

**文档搜索只覆盖你保存的标题、标签和手填摘要，不读取飞书或 Notion 正文。** 当前只支持本地工作区。每个 VSIX 包只包含标明平台的核心程序，请安装匹配 OS/CPU 的版本。

## 开发

```sh
npm ci
npm test
# 启动 IDE 前先协调，默认关闭：
# CODEMORI_ALLOW_IDE_TEST=1 npm run test:host
npm run package
```

开发需要 Node.js、Rust/Cargo 和 C 编译器。安装后的用户不需要 Rust。测试使用隔离目录；MIT 许可证。

## 项目共享

保存窗口可选择个人资料或项目共享；共享资料随项目 `.codemori/shared.json` 提交到 Git，两端显示来源并在文件变化后刷新。新建默认个人，编辑保持所属库；收藏仅属于个人。同时提交 `.codemori/.gitignore`；项目内 Markdown 正文也需随仓库提交。个人备份不包含项目共享文件。保存冲突会保留草稿，请刷新并核对新版本后重新编辑。外部文档权限仍由原平台控制。

## 文档回跳代码与署名

右键源码选择“复制代码位置链接”，将 `.codemori/project.json` 与忽略运行文件的 `.codemori/.gitignore` 提交到 Git，同事可在自己的克隆中定位。提供 VS Code/IDEA/Markdown 双入口；若文档平台禁止这类链接，可在命令面板使用“打开代码位置链接”粘贴。行号不自动跟踪重构。

首次共享写入设置显示名，两端共用 `~/.codemori/profile.json`。共享资料显示创建者与最近修改者，历史记录显示“历史未署名”。署名不代表账号认证。共享资料写入格式3，团队应使用兼容版本的插件。

## 代码旁文档提示

文件顶部 CodeLens 显示关联文档和待复核数量；设置 CodeMori › Document Hints: Enabled 或命令“显示/隐藏代码旁文档提示”控制可见性，关闭不删资料。可关联当前目录并向下继承，查看代码变化、确认说明仍适用，预览并修复移动后的文件/目录关联。新代码链接使用内容/符号锚点；歧义时提示修复。仅检查已保存代码，不读取外部正文、不存源码正文，Git仅用于本地只读差异。请一起升级两端：schema4迁移前有备份，共享格式3，备份格式2。

## 一键复核

当前文件关联区新增一键确认待复核，包含显示的继承模块项；不再逐条弹确认框。并发变化会拒绝旧确认，个人与共享分别报告结果。另提供随CLI分发的 codemori-knowledge Skill，用于AI检索/读取和说明草稿；生成草稿不自动清除复核标记。
