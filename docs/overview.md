# CodeMori 简介

CodeMori 是开源 IDE 知识连接工具。你可以保存可复用代码，把已有的文档关联到文件或目录，在写代码时找回相关说明。
<ReleaseDownloads />

## 适用场景

- **接手项目**：打开源码就能看到关联的设计说明、接口约定和业务规则，减少来回寻找文档的时间。
- **日常开发**：把飞书、Notion、Obsidian 或本地 Markdown 关联到文件和目录，在 IDE 中查看摘要、打开原文。
- **代码复用**：保存常用实现、排错方法和配置片段，配上标题、标签与使用说明，需要时搜索并复制。
- **团队交接**：将适合共享的片段、摘要和文档关联随 Git 提交，新成员拉取项目后即可查看，资料保留创建者与修改者署名。
- **维护设计说明**：代码修改后检查关联文档是否仍然适用，复核后一次确认当前文件的待复核项。

## 核心特点

- **IDE 内直接使用**：提供 VS Code 和 JetBrains 插件，无需单独启动 CodeMori 客户端，保存、搜索和关联都在开发过程中完成。
- **代码与文档双向连接**：从源码打开关联文档，也可将代码位置链接贴回文档，方便再次定位实现。详见[代码链接](code-links.md)。
- **沿用已有文档工具**：文档正文保留在原平台；支持的飞书链接可唤起客户端，Obsidian 链接交给系统打开，本地 Markdown 可在 IDE 只读预览。
- **文件与目录关联**：文档既可关联单个文件，也可覆盖目录及子目录，模块公共约定无需逐个文件重复添加。
- **可隐藏的文档提示**：在代码旁展示相关文档与待复核提示，也可以关闭提示，保留面板中的资料和关联。详见[提示设置](contextual-knowledge.md)。
- **代码变化后提醒复核**：基于已保存代码的变化提示说明待复核；确认仍适用后可一键处理当前文件关联，包含继承的模块项。
- **个人与团队资料分开保存**：个人资料默认保存在 `~/.codemori/`，明确选择的共享资料写入项目并随 Git 流转。同机两个 IDE 共用个人资料库。详见[团队共享](project-sharing.md)。
- **CLI 与 AI 工具接入**：提供独立原生 CLI、JSON RPC 和 `codemori-knowledge` Skill，可用于脚本集成、源码查询与说明草稿编写。详见[CLI](cli.md)与[AI Skill](ai-skill.md)。

## 使用流程

1. 在 VS Code 或 JetBrains 中选中代码，保存带标题的片段。
2. 将设计文档关联到当前文件，或者覆盖一个目录及其子目录。
3. 再次打开文件时，查看相关摘要并打开原文；需要时将代码位置链接粘贴回文档。
4. 代码变化后，检查说明是否仍然适用，再确认复核。
5. 选择“项目共享”，让团队需要的知识随 Git 提交和拉取流转。

## 内容来源

| 内容 | CodeMori 如何使用 |
|---|---|
| 保存的代码片段 | 保存当时的快照，按标题、描述、标签和内容找回 |
| 飞书、Notion、Obsidian 文档 | 保存入口和手填摘要，原文仍在原来的工具里 |
| 本地 Markdown | 关联后可在 IDE 只读预览；正文不加入知识搜索 |
| 源码注释 | 手动建立本地索引，支持的语言见[索引说明](indexing.md) |
| 项目共享资料 | 从项目内的共享文件读取，随 Git 流转 |
