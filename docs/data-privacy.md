# 数据存储与隐私

CodeMori 的个人知识保存在本机，团队知识由你明确选择后写入项目。产品不提供 CodeMori 云账号或云端知识同步服务。

## 数据放在哪里

| 内容 | 默认位置 | 如何迁移 / 备份 |
|---|---|---|
| 个人片段、摘要、收藏、工作区与关联 | 用户主目录 `~/.codemori/` | 插件内导出/导入个人 JSON 备份 |
| 共享显示名与本机标识 | `~/.codemori/profile.json` | 单独备份配置，或换机后重新设置 |
| 团队片段、摘要与关联 | `<项目>/.codemori/shared.json` | Git 提交、审查、拉取和历史 |
| 便于跨克隆定位的项目标识 | `<项目>/.codemori/project.json` | 与项目一起提交 |
| 原始文档正文 | 飞书、Notion、Obsidian 或本地 Markdown 原位置 | 使用原平台或文件自己的备份方式 |

Windows 的用户主目录通常为 `C:\Users\你的用户名\`；macOS 通常为 `/Users/你的用户名/`，Linux 通常为 `/home/你的用户名/`。CLI `info` 可以查看实际使用路径，`--data-dir` 可为测试或独立使用显式指定目录。

## 什么会进入团队仓库

只有明确选择“项目共享”的内容才写入共享文件。片段正文、手填摘要、标签、文档地址与署名会随该文件被仓库成员读取；原平台文档权限不会随链接转移。

个人收藏、个人资料库和源码注释索引不会自动复制到共享文件。插件不替你提交或推送 Git；提交前仍可以查看差异。

## 联网与外部应用

打开原文或在飞书中打开，会调用浏览器/应用并使用原平台的网络和权限。安装工具与构建依赖的下载也需要网络。

AI Skill 使用当前 AI 助手。虽然 CodeMori 的工具在本机读取证据，返回的代码、片段和摘要可能进入该助手的上下文；如果助手使用云端模型，应按该服务的数据政策及团队规定选择可提供的内容。**本地存储不等于使用外部 AI 时数据永远不离开电脑。**

本站使用本地搜索索引，不接入第三方搜索服务或统计脚本。部署到 GitHub Pages 后，托管请求由 GitHub 处理，适用其服务规则。

## 备份与删除

1. 从插件“更多”导出个人 JSON 备份。该备份不含远程正文、项目共享文件或署名配置。
2. 在新环境导入前查看预览；冲突保留本机版本，无效数据不会部分导入。
3. 项目目录变化后使用“重新定位工作区”，文档的独立绝对地址需要另行修正。
4. 卸载插件不会自动删除资料。如要彻底删除，先备份，再关闭使用中的 IDE，确认后自行删除个人目录；共享资料通过团队 Git 流程移除。

不要把正在使用的 SQLite 文件当作普通同步文件在多机间直接覆盖。优先使用导出/导入或 Git 共享，避免覆盖尚未合并的修改。
