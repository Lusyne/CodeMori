# 随 Git 共享项目知识

CodeMori 可以让团队共用代码片段、手填摘要、文档链接和源码文件关联。每个人仍在原来的飞书、Notion 或 Obsidian 中编辑正文，CodeMori 在 IDE 里提供相关入口。

## 开始使用

1. 打开本地项目，保存片段或关联文档。在保存窗口将默认的“个人资料”改为“项目共享（随 Git）”。
2. CodeMori 创建 `<项目>/.codemori/shared.json` 和 `.codemori/.gitignore`。检查内容后，将这两个文件正常提交到项目 Git 仓库；需要共享的本地 Markdown 文件也要提交。
3. 后续修改沿用团队的提交、审查和合并流程。插件监听共享文件变化，拉取或切换分支后刷新显示；插件自身不执行 Git 提交、推送或拉取。

若仓库忽略了整个 `.codemori/` 目录，需要团队自行调整 Git 忽略规则后提交。项目根目录取 IDE 当前文件所属的本地工作区；多根工作区的资料按当前项目展示。

## 个人与团队的边界

| 内容 | 位置与共享方式 |
|---|---|
| 个人片段、摘要、关联、收藏 | `~/.codemori/`；原个人备份功能 |
| 明确保存为项目共享的片段、摘要、文档链接与文件关联 | `<项目>/.codemori/shared.json`；随 Git 分支和提交流转 |
| 飞书／Notion／Obsidian 正文 | 保留在原平台；不下载、不同步，也不加入搜索 |
| 手动建立的源码注释索引 | 本机可重建数据；不写入共享文件 |

面板可筛选“个人 + 当前项目共享”“个人资料”“当前项目共享”，每条资料有来源标记。当前文件的关联区域同时显示两类关联。新建默认个人；编辑时不能切换所属资料库，避免无意公开个人内容。共享记录不提供个人收藏按钮。

个人 JSON 备份不包含项目共享文件；共享文件使用 Git 历史备份。卸载插件不会删除这两处资料。仓库成员可读共享片段和摘要，因此只把适合提交到该仓库的内容选择为项目共享。

## 路径和文档权限

源码关联保存项目相对路径，本地文档保存为 `./docs/guide.md` 一类相对地址；团队成员克隆到不同目录后，从自己的项目根目录解析。源码行号仍是保存时的位置参考。不能共享项目外的本地文件，也不接受经过符号链接的共享本地文档路径。文件更名后可以手动修复关联。

飞书与 Notion 保存原链接，访问权限仍由原平台决定；共享链接不等于自动获得文档权限。符合支持范围的飞书文档才显示“在飞书中打开”，其他链接保留原文入口。

共享 Obsidian 链接须使用 `vault` 和相对 `file`，不能带某台电脑的绝对 `path`。团队成员需要有对应名称的库及笔记；CodeMori 不分发 Obsidian 库。需要更容易随项目迁移的说明时，可以使用仓库内的 Markdown。

## 冲突与限制

每次写入核对打开草稿时的整个文件版本；如果另一 IDE、Git 或团队成员的新提交改变了它，保存会提示冲突并保留草稿。先保留自己的编辑内容，刷新并重新打开记录、确认差异后再保存，不能用旧草稿直接覆盖新版本。

存在 Git 冲突标记、无效 JSON 或不支持的格式时，共享区域显示错误，个人资料仍可用。CodeMori 不覆盖或自动修复该文件，需先正常解决 Git 冲突。协作写入使用文件锁和原子替换；这不是实时多人编辑服务，也不提供共享账号或文档权限管理。

当前实现每次读取会校验并构建整个共享文件的临时查询视图，适合先以项目精选资料试用；尚未建立大型共享库性能承诺。此前一万条个人资料的性能数据不代表同等规模的共享 JSON。

## 共享资料署名

首次写入共享资料时，插件会要求设置显示名，也可使用“设置共享署名”修改。该配置保存在个人目录 `~/.codemori/profile.json`，同机的两端 IDE 共用；不会自动读取或公开系统用户名、Git 邮箱。Windows 通常为 `C:\Users\用户名\.codemori\profile.json`。

共享片段与文档显示创建者、最近修改者。新记录保存两项署名；编辑保留原创建者，只更新最近修改者。改显示名不回写历史记录。纯关联/解除关联不冒充正文编辑；删除历史仍通过 Git 查看。署名是用户自报的名称和本机生成的标识，不是账号认证或权限控制；同名用户、换机重新配置身份时不能据此认定是同一个人。

历史记录显示“历史未署名”；首次编辑后仍保留未知创建者，只记录这次修改者。不要把 Git 提交者自动视作资料创建者。

要从文档回到源码，可使用[代码位置链接](code-links.md)，并将项目 `.codemori/project.json` 一并提交。

## 模块继承与复核

支持递归目录关联、已保存代码变更提醒、人工确认和移动路径批量修复。共享写入格式3，保留署名与复核字段；仍读取旧格式1/2，旧关联没有基线时显示未确认。个人数据库升级schema4，备份导出格式2/读取1和2。请一起升级两端插件。[使用与边界](contextual-knowledge.md)。
