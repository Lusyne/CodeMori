# 快速开始

使用插件不需要 Rust、Node.js、数据库配置或独立客户端。
## 安装

先按操作系统和 CPU 选择包。

- **VS Code**：打开扩展视图的“…”菜单，选择“从 VSIX 安装”，选择匹配平台的 `.vsix`。按提示重新加载后，点击`侧边工具栏`使用或在命令面板运行 `CodeMori: 搜索资料`。
- **Jetbrains**：Settings/Preferences → Plugins → 齿轮 → Install Plugin from Disk，选择匹配平台的 JetBrains `.zip`。重新加载后，点击`侧边工具栏`使用或用 Find Action 运行 `CodeMori: 搜索资料`。

插件已包含 CLI。独立 CLI 压缩包供命令行使用，不需要再给插件安装一次。插件读取资料时会按需创建 `~/.codemori/`。

## 可找回的片段

1. 打开本地工程中的源码文件，选中一段代码，右键选择 `CodeMori: 保存选中代码`。
2. 输入标题，例如“重试条件”；标签和描述可以先留空，然后保存。
3. 在 CodeMori 搜索“重试”。两个词需要同时命中已保存字段。
4. 选择结果查看快照，点击“复制”，在需要的位置自行粘贴。

保存的是快照。原文件之后改变不会自动更新片段；来源路径和行号用于找回上下文。

## 让文件带上设计说明

1. 保持源码文件打开，点击 CodeMori 的“关联文档”。
2. 填写标题与已有笔记地址。可用飞书／Notion 的 HTTP(S) 链接、Obsidian `open` URI，或本地 Markdown 的完整路径。
3. 可选填写一句摘要，例如“超时可重试，业务拒绝不重试”。保存后，当前文件区域直接显示标题、来源和摘要。
4. 再打开该源码文件时，从当前文件区域查看摘要；需要全文时点击“打开原文”。网页使用浏览器，Obsidian URI 使用系统关联的应用，本地文件在 IDE 中打开。

搜索只覆盖保存的字段，不会自动读取飞书／Notion／Obsidian 正文。只有你手动索引的受支持源码注释会成为额外搜索来源。

Obsidian 地址仅支持打开笔记的参数（`vault`、`file`、`path`、`paneType`），不接受追加内容或回调参数。若旧链接因此被拒绝，编辑记录并粘贴 Obsidian 的普通“复制 Obsidian URL”链接即可。

## 备份和离开

从“更多”导出个人资料 JSON 备份，包含片段、摘要、标签、工作区和文件关联；外部正文不在备份内。导入时先查看新增、冲突和无效记录数量。冲突保留本机版本，无效数据不会部分导入。

备份移到另一台电脑或另一目录后，用“重新定位工作区”更新项目根目录，片段来源与文件关联保留相对路径。文档记录中的本地文件链接是独立的绝对地址，若笔记文件也移动了，需要编辑该链接。

关闭 IDE 后无需停止后台服务。卸载插件不会自动删除 `~/.codemori/`；重新安装后仍可读取原资料。需要清空资料时，先备份并确认，再自行处理该目录。

更多操作：[VS Code](vscode.md) · [JetBrains](jetbrains.md) · [注释索引与预览](indexing.md)。

飞书文档另有 **在飞书中打开** 按钮，可直接请求客户端打开；保留原始链接和浏览器入口。支持范围及桌面限制见[飞书打开说明](feishu-opening.md)。

## 团队使用

保存时选择“项目共享（随 Git）”，再将项目中的 `.codemori/shared.json` 与 `.codemori/.gitignore` 提交到 Git。同事拉取后会自动看到共享资料与当前文件关联，个人资料和收藏仍保留在本机。个人备份不包含共享文件；共享内容由 Git 备份。详见[项目共享指南](project-sharing.md)。

## 文档回跳代码与署名

源码中使用“复制代码位置链接”，把链接贴进文档；将项目 `.codemori/project.json` 提交给同事。文档平台不能点击时，使用“打开代码位置链接”粘贴。详见[代码链接指南](code-links.md)。首次共享写入会提示设置显示名，列表显示创建者和最近修改者；团队应一起升级到当前0.1.0；共享文件写入格式3并保留署名和复核信息，详见[署名和旧资料迁移](project-sharing.md)。

## 文档提示、模块继承与复核

关联窗口可选“当前目录（含子目录）”；面板显示继承来源、代码是否变化及最后确认信息。代码旁提示默认显示，可从设置/更多菜单隐藏，关联资料保留。当前文件文档可查看Git差异（需可用基线）和确认仍适用；文件/目录移动后可预览并批量修复。新代码链接带内容/符号锚点。详见[完整操作及升级说明](contextual-knowledge.md)。

## 一键复核与skill

当前文件关联区可一次确认显示的待复核项，包含继承模块；会检查版本和代码指纹并分别报告个人/共享结果。CLI压缩包还提供 `codemori-knowledge` Skill，供AI查找实现、读取关联知识并生成文档草稿。详见[使用与安装](ai-skill.md)。
