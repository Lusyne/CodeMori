# 一键复核与 AI Skill

## 一键确认当前文件

在当前文件关联区域点击“一键确认待复核”，一次确认当前显示的待复核项，不再逐篇弹确认框。适合你已检查过改动、确认只是格式调整或说明仍然适用的情况。

范围是当前文件关联区中的个人与共享资料，包含继承的模块；模块项会确认其整个目录的代码基线。主搜索列表的筛选不会扩大或缩小这个关联区。没有基线、代码不可检查和未变化的项不会被悄悄纳入。共享署名尚未配置时，仍需完成一次署名设置。

按钮使用显示时的代码指纹、关联信息、文档版本和共享文件版本。显示后内容又变化，会要求刷新，不自动用新版本重试。同一个资料库中整批成功或整批不更新；个人与共享是两份存储，若一边失败，界面明确列出已确认数量及未完成原因。

格式变化可能影响语义，因此系统保留人工点击，不自动把所有空白改动认定为安全。生成说明草稿也不会自动清除待复核标记。

## 安装 Skill

Skill 名为 `codemori-knowledge`，源码在仓库 `skills/codemori-knowledge/`。它随0.1.0 CLI压缩包一起提供，无需启动服务或配置产品账号。桥接脚本需要Python3，原生CLI无需Rust工具链。

从解压后的CLI目录运行：

```sh
python3 skills/codemori-knowledge/scripts/install.py
```

安装到 `$CODEX_HOME/skills/codemori-knowledge`；未设置时为 `~/.codex/skills/codemori-knowledge`。安装器同时复制当前平台CLI和许可证，因此其他项目中使用Skill时不必查找插件内的可执行文件。Windows使用环境中的Python命令并选择Windows CLI包。

从源码工程安装，可先构建CLI，再运行同一命令。自定义核心使用 `--cli /path/to/codemori`。更新时从新版本的解压目录运行并添加 `--replace`；旧安装会移到技能目录之外的 `skill-backups/`，不会静默删除原有内容。

## 使用示例

可以向支持此Skill的助手提出：

> 使用 $codemori-knowledge 查找当前项目里支付重试的实现，结合已关联的设计摘要解释哪些错误会重试。

> 使用 $codemori-knowledge 阅读 src/payment 的实现，生成 docs/payment-design.md 草稿，引用源码位置，并列出已有说明中需要复核的地方。

工具提供证据，当前AI助手负责理解和写作。没有内置模型、API密钥或自动发布流程。Skill会区分当前已保存代码、旧片段快照和手填摘要，不把链接当作已经读取的飞书/Notion/Obsidian正文。

## 可调用工具

| 命令 | 用途 |
|---|---|
| `context --root ... --query ... [--file ...]` | 当前项目的个人/共享知识、源码命中和文件关联/复核状态 |
| `search --root ... --query ... [--under src]` | 按忽略规则搜索已保存文本，返回路径、行号和片段 |
| `read --root ... --file ... --start 1 --end 100` | 读取指定源码范围及指纹 |
| `link --root ... --file ... --line 20` | 生成可移植的IDE代码位置链接 |

命令由 `scripts/codemori_tool.py` 提供。需要独立指定核心或测试库时，将 `--cli` 和 `--data-dir` 放在子命令之前。`CODEMORI_CLI` 也可指定核心。助手也可以直接使用已文档化的JSON RPC。

检索是字面量关键词匹配，不是语义搜索；找不到时可以改用函数名、错误信息或助手原有的仓库工具。返回的 `truncated`、跳过数量和诊断表明覆盖范围，不能把不完整搜索说成“项目中不存在”。只读取磁盘上已保存的内容。

搜索限制为2000个文件、10000个遍历条目、64MiB累计文件体积；单文件2MiB，返回最多50处匹配。组合知识上下文最多512KiB，过大时需缩小查询范围；按行读取最多200行/64KiB，超限会报错或明确截断。检索和读取不修改知识记录、复核状态或源码，但首次访问可能初始化本地库、登记项目映射；生成链接可能创建项目标识文件。

发布到飞书/Notion、保存为共享资料、Git提交及人工复核不由Skill自动执行。文档草稿的事实与表达质量仍需检查；工具集成测试不能代替模型生成质量评估。
