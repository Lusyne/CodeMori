# 兼容性与使用限制

安装包按操作系统和 CPU 分发，不能跨平台混用。

## IDE 支持范围

| IDE | 声明范围 | 已验证范围 |
|---|---|---|
| VS Code | 本地工作区，最低1.96 | macOS 实际扩展宿主；0.1.0 验证使用1.140.0 |
| IntelliJ IDEA | 2024.2 起 / build242，无最高版本限制 | 2024.2、2026.1.2 各 40 项测试通过；二进制 API 兼容检查通过 |
| RustRover | 同上 | 2026.2.3 / RR-262.10968.75 二进制 API 兼容检查 |
| 其他 JetBrains 产品 | 同一平台版本范围 | 尚未逐一完成产品验收 |

JetBrains 插件保留最低版本限制，因为当前实现使用 Java 21。取消最高版本限制可以避免 IDE 升级后仅因版本号无法安装，但不代表所有未来版本都已验证；平台 API 改动仍可能需要适配。

检查工具为 JetBrains Plugin Verifier 1.410，上述三个版本均返回 Compatible，无插件弃用或内部 API 使用报告。保存对话框和文档提示刷新通过适配层优先使用新版公开接口，仅在旧版未提供新接口时使用旧形式；核心程序从插件自身 JAR 所在目录定位。适配分支另外经过实际调用测试，不能仅凭静态检查判断反射调用是否有效。这些检查不等同于各产品的完整桌面验收。

## 操作系统与架构

| 平台 | CLI 核心与包验证 | 当前限制 |
|---|---|---|
| macOS arm64 | 原生执行 | 主要开发与 IDE 验证平台 |
| macOS Intel | 通过 Rosetta 执行核心测试 | 未完成本版本完整 IDE 桌面验收 |
| Linux arm64 | 容器中执行核心测试 | 历史 VS Code 宿主验收不代表本版本全部重跑 |
| Linux x64 | 仿真容器中执行核心测试 | 不据此承诺原生硬件性能或完整桌面兼容 |
| Windows x64 | 交叉构建与文件结构检查 | 实机运行验收暂缓 |

## 文档打开与代码链接

- 飞书客户端打开在 macOS 上有实际接收验证；Windows/Linux 唤起尚未实机验证。
- Notion HTTP(S) 链接使用浏览器；Obsidian `open` 链接交给系统关联的应用。
- VS Code 代码链接有实际 URI 接收验证；JetBrains 已验证平台处理器，OS/Toolbox 路由仍需单独确认。
- 文档平台可能拦截自定义协议；可在 IDE 使用“打开代码位置链接”粘贴。

## 数据与升级

个人数据库 schema4、个人备份导出2/读取1和2、共享文件写入3/读取1到3，项目标识与署名配置为1。

旧数据库升级前会生成一致性备份，旧核心拒绝较新的数据格式。升级前仍建议导出个人备份；同机两端插件和团队成员使用兼容版本。详见[数据存储](data-privacy.md)。

## 能力边界

知识搜索不读取远程文档全文，本地 Markdown 预览正文也不加入搜索。源码注释索引首批支持 Java、JS/TS及Python；检索不是语义搜索。

关联以文件/目录为范围，复核针对已保存代码。模块复核覆盖整个目录；个人与共享库之间没有跨库事务，可能出现已明确报告的部分成功。

共享通过 Git 流转，不提供实时多人编辑或账号权限控制。大型共享文件和大型模块暂无性能承诺；AI 工具测试不代表生成文档的事实准确率。
