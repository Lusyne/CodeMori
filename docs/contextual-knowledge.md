# 代码旁的项目知识

本版增加可隐藏的文档提示、关联代码复核、模块级继承，以及更耐用的代码位置链接和路径修复。

## 显示或隐藏文档提示

- **VS Code**：文件顶部显示 CodeLens，例如“CodeMori · 2 篇文档 · 1 项待复核”。点击进入 CodeMori。设置里的 **CodeMori › Document Hints: Enabled** 可关闭；也可执行“CodeMori: 显示/隐藏代码旁文档提示”或使用面板“更多”。命令在打开的工作区保存偏好，无工作区时使用用户设置。VS Code 全局 CodeLens 也需处于启用状态。
- **JetBrains**：文件首行的行号区域显示文档图标，悬停查看数量和复核提示，点击打开 CodeMori。面板“更多”可选择隐藏/显示，偏好保存在当前项目；IDE 的 Editor → General → Gutter Icons 中也可控制 CodeMori 图标。

默认显示。开关只改变提示的可见性，不解除关联、不删除资料。提示针对整个文件及其继承的模块文档；当前没有函数级文档绑定，也不向源码写注释。

## 一份说明关联整个模块

关联文档时，在保存窗口将“关联范围”选为“当前目录（含子目录）”。例如从 `payment/service.ts` 发起关联，说明会绑定到 `payment/`，打开其下任意源码文件均可看到。根目录文件的“当前目录”表示整个项目。

已有文档也可使用“关联到当前目录”。个人资料、项目共享均支持；共享关联随 Git 流转。面板明确显示“继承自目录：payment”，与直接文件关联分开。一篇文档既绑定文件又绑定目录时，提示的文档数量去重，关联列表保留各项来源。

解除继承关联会解除原目录的这项关联，影响其子文件；不是只为当前文件隐藏。解除关联不会删除外部文档。`payment/` 不会匹配 `payments/` 等名称相近的目录。

## 关联代码变更与复核

首次关联时，在能读取代码的情况下建立已保存代码的指纹基线。此后面板与代码旁提示检查内容变化：

| 状态 | 含义 |
|---|---|
| 代码未变更 | 已保存代码的指纹与基线一致；不是对文档正确性的自动保证 |
| 代码已变化，说明待复核 | 关联代码变化了，需要人确认说明是否仍适用 |
| 尚未确认基线 | 旧关联或初次无法读取目标；可读后手动确认 |
| 代码暂不可检查 | 文件缺失、权限、读取范围或大小限制等；不当作“未变更” |

从当前文件关联列表选中文档，使用“查看关联代码变化”或“确认说明仍适用”。确认会记录时间与可用的本机署名；共享确认使用已配置的共享署名。若代码、文档版本或关联在操作过程中变化，会拒绝旧确认，需刷新后核对。

只有确认时存在干净的 Git 提交基线，才可展示该提交到当前已保存代码的差异。未提交、被忽略的文件、浅克隆缺少旧提交、无 Git 或超出差异限制时仍可用指纹状态，但没有历史源码差异。CodeMori 不自动抓取外部文档正文，不用 AI 判定说明对错，不持久化源码正文。Git 操作限本地只读状态/历史差异，不执行提交、拉取、推送或网络同步。

文件检查限 UTF-8、2 MiB，CRLF/LF统一后比较。模块按忽略规则检查常见源码扩展名（Java/Kotlin、JS/TS、Python、Rust、Go、C/C++、C#、Ruby、PHP、Swift、Scala、Vue/Svelte、SQL、Shell），不把 Markdown/图片变化冒充代码变化。遍历最多2000个非忽略文件、累计检查源码不超过64 MiB；超过限制或模块中没有可检查的源码时显示不可检查。目录遍历跳过符号链接、隐藏和常见构建目录。Git命令限5秒、差异输出限1 MiB。

## 更耐用的代码位置链接

新复制的链接带内容指纹和可用的函数/类锚点。原文件未变更时按原位置打开；插入行后尝试找回代码内容或符号。Java、JavaScript/TypeScript、Python使用已有语法解析器；其他UTF-8文本使用内容指纹。符号正文变化后可能定位到函数/类开头，而不是旧行号。

文件移动后，插件在受限的项目范围中查找唯一匹配。完整文件指纹一致，或支持语言中的符号能唯一匹配时，可以定位到新位置。若有多个副本、符号被重命名/删除、超出扫描范围或无法唯一判断，会提示重新生成或修复链接，不随便选择一个位置。源码语法嵌套限256层。原0.3位置链接继续按原路径/行号打开；旧插件不能理解带锚点的新链接，应一起升级。

这不等同于任意语言的语义重构追踪。文件、类和函数同时大幅改名/改写时，仍需人工更新文档中的链接。

## 修复移动后的文件或目录关联

在面板“更多”选择“修复移动后的文件/目录”，选择个人或共享资料，输入旧、新项目相对路径。新目标必须已存在。确认前显示受影响的关联与片段来源数量，再应用同一批修复；目标已有冲突关联或预览后数据变化时拒绝覆盖。

目录修复同时处理其下的关联和片段来源；历史复核基线保留，代码变过仍会提示待复核。该操作不会移动磁盘文件，也不会修改外部笔记内容或旧链接字符串。

## 升级

个人数据库升级到schema4前先生成在线一致性备份；个人备份导出格式2，仍可导入格式1。共享文件读取格式1/2/3，写入格式3。新增字段保存模块范围与复核记录。团队和同机两端插件应一起更新到兼容版本；旧核心拒绝新格式，不能继续混写。项目ID格式和署名配置格式仍为1。

## 当前文件一键复核

关联区新增一键确认待复核，范围由当前显示的关联决定，包含继承模块。显示后代码/文档/关联发生变化会拒绝旧确认；两份资料库的部分成功分别报告。不会自动忽略格式变化。[操作与AI工具](ai-skill.md)。
