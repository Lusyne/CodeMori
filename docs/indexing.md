# 源码注释与本地 Markdown

注释索引是可重新生成的辅助数据。保存的代码快照、文档摘要与文件关联仍是用户资料，完整备份包含这些资料；不包含源码索引或 Markdown 正文。

## 注释索引

两个 IDE 的“更多”提供“索引当前文件注释”和“增量索引当前工作区注释”。它读取已保存的磁盘文件；不会替用户保存尚未提交的编辑器缓冲区。全文内容指纹未变化的文件跳过解析，变化文件重新解析，删除或新被忽略的文件会清理旧索引。重新定位工作区后需再次索引。

| 语言 | 文件扩展名 | 范围 |
|---|---|---|
| Java | java | 行注释、块注释、Javadoc |
| JavaScript | js、jsx、mjs、cjs | 语法树中的注释，含 JSX 注释 |
| TypeScript | ts、mts、cts、tsx | 语法树中的注释 |
| Python | py、pyi | `#` 注释；docstring 是字符串，不纳入 |

使用 Tree-sitter 语法解析，避免把 URL、正则表达式、普通字符串和模板字符串误认作注释。暂不支持 Kotlin、Go、Rust、C/C++ 等语言的自动注释索引；这些语言仍可手动保存代码片段。

遵守 `.gitignore`、`.ignore`、Git 全局忽略规则，项目没有 `.git` 目录时仍应用本地忽略规则。默认排除隐藏文件／目录、符号链接，以及 `node_modules`、`target`、`build`、`dist`、`vendor`、`__pycache__` 目录。单文件索引也遵守这些规则。

只接受 UTF-8、最多 2 MiB 的普通文件。包含语法错误的文件不建立索引，防止错误恢复把源码误归类为注释。操作结果展示更新、未变、清理、跳过、失败数量及最多 100 条诊断；忽略规则排除的文件未被遍历，不计入跳过数。单个文件失败会清除其旧索引；目录遍历或存储失败则回滚整个批次。

数据库仅保存注释文本、项目／文件／行号、语言、内容指纹及索引时间，不保存源文件正文。搜索支持中文和混合关键词的 AND 子串匹配，并展示命中上下文。片段／摘要和注释分别分页；同一搜索框与项目范围同时作用于两组结果。标签和收藏筛选不适用于注释。

结果上的索引时间是上次解析时间。没有文件监听器；源码变更后请增量索引。跳转前会校验文件指纹，过期时提示重新索引。索引少量或零注释的项目无法提供完整项目解释。

## 本地 Markdown 只读预览

先将本地 `.md` 或 `.markdown` 文件保存为文档资料。VS Code 在资料操作中选择“Markdown 只读预览”；JetBrains 在“操作…”中选择同名入口。预览读取当前磁盘文件，支持 UTF-8、最多 2 MiB。

正文由核心渲染，保留标题、列表、代码、表格等基本排版；原始 HTML 显示为文本，图片只保留替代文字，链接只保留标签。预览不加载远程或本地资源、不执行脚本、不提供编辑或链接跳转。需要完整功能时仍可选择“打开原文”交给 IDE。

预览正文和 HTML 不落入数据库，不加入搜索，也不随备份导出。飞书、Notion 等远程文档保持“链接＋手填摘要”的边界。
